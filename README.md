# Enterprise Jira Issue Tracking & Slack Notification Service

## Project Overview

This project is a backend service that monitors Jira issues and automatically sends notifications to Slack channels.

It also generates daily and weekly reports about project activities.

## Features

- Jira REST API Integration
- Slack Notifications
- Daily & Weekly Reports
- Scheduler
- PostgreSQL Database
- Docker Support
- Logging
- Exception Handling
- Unit Testing
- FastAPI Dashboard

## Tech Stack

- Python
- FastAPI
- Jira REST API
- Slack API
- PostgreSQL
- SQLAlchemy
- APScheduler
- Docker
- GitHub Actions
